Version 11 adds the deterministic stage
`code/v11_level_energy_entropy.py`. It reads only arrays generated by
`code/build_data.py`, uses the documented range `N=10^6`, and contains no
random component.

The Version 9 numerical pipeline was rerun in Python and retained inside the
Version 11 package. Earlier follow-up values for which no reproducible source
script was available were recomputed, and the manuscript was updated to the
regenerated outputs when protocols differed.

Measured finite-range laws remain labelled as measurements in the manuscript. They are not promoted to asymptotic theorems.
