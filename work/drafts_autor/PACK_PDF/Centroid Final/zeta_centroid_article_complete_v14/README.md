Package: Triangular Centroids of Exponential Walks on Riemann Zeta Ordinates
Version: v14

Contents
--------
- zeta_rvm_exponential_centroids_v14.tex : LaTeX source of the article.
- zeta_rvm_exponential_centroids_v14.pdf : Compiled manuscript.
- figures/ : Figures used in the paper (PNG and PDF).
- scripts/ : Python scripts used to generate the main figures and numerical checks.
- outputs/ : Complete numerical outputs produced by the scripts.
- data/ : Derived CSV tables used by the manuscript and the figures.
- data/input/ : Input binary files used by the scripts.
- zeross.bin, zLamb.bin : Convenience copies of the same input files kept at the package root.
- source_notes/ : User-supplied source note incorporated into the article workflow.
- SHA256SUMS.txt : SHA-256 manifest for the files distributed in this package.

Main input data
---------------
- zeross.bin : true-zero ordinates (Odlyzko table, local binary copy).
- zLamb.bin : Lambert sequence paired with the same ordinal range.

Reproducibility
---------------
The introductory trajectory figures are generated by
  scripts/rvm_residual_walks.py
using zeross.bin and zLamb.bin.

The additional numerical plots are generated by
  scripts/make_article_figures.py
and the independent checks are provided by the scripts
  scripts/verify_rvm_centroid.py
  scripts/verify_centroid_rh_equivalence.py
  scripts/verify_zeta_conditional_constant.py

SHA manifest
------------
SHA256SUMS.txt lists the SHA-256 digest of every distributed file in this
package except the manifest itself and the final zip archive.
