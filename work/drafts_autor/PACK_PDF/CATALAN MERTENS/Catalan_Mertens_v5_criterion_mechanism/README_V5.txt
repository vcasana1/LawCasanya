Version 5 preserves the full introduction, Catalan theory, physical routes,
bibliography, numerical outputs, and Python appendices.  It adds the exact
characterization

  X not in E_RH  <=>  RH,

where E_RH is the global exceptional Catalan class measured at current
compressed time.  The paper distinguishes this exact criterion from the
strictly stronger local Brownian prefix and moment conditions.  Equivalence
of the criterion to RH is not called circular; the still-open problem is an
independent arithmetic mechanism proving exclusion from E_RH.
