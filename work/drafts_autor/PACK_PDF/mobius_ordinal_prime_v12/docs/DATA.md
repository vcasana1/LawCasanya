# Data files

All arrays were regenerated by the Python pipeline for `1 <= n <= 10^6` unless noted otherwise.

- `mu.npy`: Mobius values.
- `M.npy`: Mertens partial sums.
- `Q.npy`: squarefree counting function.
- `Np.npy`, `Nm.npy`: positive and negative occurrence counters.
- `S.npy`, `SS.npy`: ordinal-prime transform and cumulative transform.
- `T.npy`: signed consecutive-prime block after removing the zero contribution.
- `E.npy`, `E_mid.npy`: residuals.
- `pr.npy`: one-based prime table, extended through the full formal recovery domain required in Version 9.
- `P.npy`: prefix sums of the prime table.
- `p_star.npy`: interpolated prime at the window centre.
- `gaps.npy`, `kappa.npy`, `sd_corr.npy`, `sd_indep.npy`: prime-gap covariance data and variance predictions.

The data files are generated, not external empirical inputs.
